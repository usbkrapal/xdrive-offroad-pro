# Terrain Monitor / xDrive Offroad Pro

Версия: 0.7, 17 ноября 2026. Этап: веб-прототип и первая нативная реализация для BMW X7 G07 / iDrive 7. В 0.5 движение перенесено на поверхности шин и сами агрегаты, обновлена графика в «Подвеске»/«Системах». В 0.6 приборы тангажа/крена стали круглыми с прежними изображениями BMW; тормозящие колёса подсвечиваются красным, а при одновременной пробуксовке красная подсветка мигает (DESIGN_UPDATE_05.md).

## Цель

Проверить интерфейс расширенного off-road монитора в desktop browser, затем отдельно адаптировать его к MGU Store. Веб-прототип работает исключительно с синтетической телеметрией и постоянно показывает маркировку «ДЕМО». Нативная версия по умолчанию тоже работает в демо; отдельно выбирается экспериментальное чтение восьми базовых показателей через allowlist. Неподдержанные или пропавшие данные не подменяются демо. Команды автомобилю не отправляются. Локальный запуск — preview без SDK; реального подключения ещё не было.

ChatGPT ведёт спецификацию, исследование, проверку реализации и постановку доработок. Код приложения пишет Claude CLI. Спецификация и SIGNALS.md должны существовать до начала реализации. Подтверждения в исходниках не означают проверку на конкретном G07.

## Продукт и визуальное направление

- Рабочее имя в шапке: Terrain Monitor; подзаголовок xDrive Offroad Pro (префикс модели убран по запросу пользователя).
- Основной язык — русский; английский добавляется через словарь без переписывания компонентов. Обозначения FL/FR/RL/RR сопровождаются русской расшифровкой: ПЛ/ПП/ЗЛ/ЗП.
- Стиль существующего idrive7-apps: почти чёрный фон #04060a, белые цифры #f4f7fb, вторичные подписи #8a95a6, ледяной голубой #81c4ff, красная активная вкладка #ef2b2d. Плоские тёмные панели, тонкие линии, маленькие M-полосы. Никаких заимствованных BMW логотипов, шрифтов или моделей.
- Крупные табличные цифры; важные значения 40–64 px на desktop, не менее 28 px в компактном режиме. Читаемые подписи, контраст, явный focus. Не зависеть только от цвета.
- Качественный AI-generated CGI cutaway: полупрозрачный кузов, видимые двигатель/АКПП/раздатка/кардан/дифференциалы/колёса и стойки. Отдельные SVG-слои анимируют показания узлов. Это 2.5D визуализация, не rigged CAD-модель; углы показываются отдельными индикаторами. Не использовать GPL renderer/gfx или заимствованные неподтверждённые модели. Источник asset и промпт — ASSET_PROVENANCE.md.
- Проверочные размеры браузера: 1440×900 desktop, 1920×720 (upstream MGU-профиль, ещё не подтверждённый на данном G07), 1600×520 canvas, компактный 1280×480 и мобильный 390×844. На широком MGU-профиле шапка/навигация, pitch/roll, высота, уровень подвески, угол руля и текущая скорость доступны без прокрутки; на малом экране допустима вертикальная прокрутка дополнительных деталей.
- Верхняя навигация из пяти вкладок; режимы локального симулятора визуально отделены и прямо названы «Сценарий демо». Уровни подвески и DSC/HDC являются показаниями, а не кнопками управления автомобилем.

## Экраны

### Рельеф (Terrain)

Крупная центральная прозрачная схема агрегатов с анимацией их показаний, отдельные хорошо различимые индикаторы тангажа и крена с ° и знаками. Тангаж + = нос вверх, крен + = наклон вправо; эти направления заданы лишь для mock-модели до проверки native convention. Нельзя обозначать pitch_rate/roll_rate как угол или делать порог «безопасного» опрокидывания.

Показать: текущие pitch/roll; высоту над уровнем моря; угол руля (именно рулевого колеса); текущий уровень подвески; скорость; передачу; статус HDC и заданную скорость при наличии. Отметка ПЕРЕД, понятная ориентация четырёх колёс, аккуратные выноски агрегатов. Сводка сессии: max |pitch|, max |roll|, min/max altitude, max slip. Значения высоты и углов в прототипе — mock, не измеренные. В интерфейсе достаточно постоянной метки «Демо»; инженерные оговорки и формулы остаются в документации.

### Сцепление (Traction)

Показать схему трансмиссии/четырёх колёс, раздельно: передняя/задняя доля момента (%), фактический момент на передней оси (Н·м), источник распределения. В mock явно помечено «Демо»; в будущем native / estimated / unknown различаются. Нельзя выдавать разность engine torque − front axle torque за момент задней оси: это разные точки трансмиссии.

Четыре колеса: скорость каждого (км/ч), slip (%) и состояние тормозного вмешательства (активно / нет данных / не активно). Блокировка заднего дифференциала: состояние и доля только если есть отдельный достоверный сигнал; отсутствие опции не равняется 0%. Для неизвестного показывать «— / Нет данных».

Wheel slip в этой версии — условная синтетическая неотрицательная величина 0–100%, независимая от wheel speed, не физическая модель. Вычисленное отклонение скорости колеса от среднего нельзя переименовывать в физическое проскальзывание. Для такой будущей оценки отдельное имя «разница скоростей» и источник estimated. Ключевые добавочные показатели: max slip по колёсам, угол руля, скорость, пиковый момент за сессию.

### Подвеска (Suspension)

Схема четырёх углов: FL/FR/RL/RR с высотой относительно калиброванной нормы, мм; до калибровки не называть дорожным просветом. Показать signed отклонение каждого угла, левую/правую и переднюю/заднюю разницы, общий размах max−min. Формулы: frontDelta=FL−FR; rearDelta=RL−RR; leftRight=(FL+RL−FR−RR)/2; frontRear=(FL+FR−RL−RR)/2; range=max(FL,FR,RL,RR)−min(FL,FR,RL,RR). Если любой необходимый вход invalid/stale/unavailable, соответствующая производная недоступна. Эти величины не эквивалентны ходу колеса или сертифицированной артикуляции.

Текущий уровень как единственный индикатор. Поддержать отображаемые enum Offroad / High / Normal / Dynamic / Sport / Loading и unknown, с русскими подписями. Это предложенная продуктовая модель; наличие всех режимов на конкретной комплектации G07 не подтверждено. Симулятор может последовательно демонстрировать разные уровни. Нельзя показывать ряд кнопок смены реальной подвески.

### Системы (Systems)

Панели: HDC status + set speed; DSC/DTC status; передача; педаль акселератора (%) с корректной подписью; положение дросселя (%) отдельно; крутящий момент двигателя; температура АКПП, ОЖ и масла; давление и температура всех четырёх шин. Дополнительно уместны обороты, ускорение по продольной/поперечной оси и yaw rate, если реализация не перегружает интерфейс.

Давление в bar, температуры °C, скорость км/ч, момент Н·м, altitude м. Статус fresh/stale/unavailable виден текстом или компактным значком с доступным названием. В демо потери данных показывать «—», не 0 и не зависшее правдоподобное значение.

### Камеры (Cameras)

Крупный передний ракурс и два боковых, с возможностью выбрать основной вид. В v0 это только локальные статичные демонстрационные изображения с явной подписью. В «Нет части данных» левый ракурс заменяется заглушкой. Нет реального видеотранспорта, управления камерами или рассчитанных по картинке расстояний/траекторий. Подробности: CAMERAS.md; доступ к реальным потокам — unknown в SIGNALS.md.

## Телеметрия и достоверность

SIGNALS.md — источник истины о подтверждении адресов и масштаба. В модели каждого сигнала отдельные поля: value (nullable), unit, updatedAt, runtimeSource (mock / measured / estimated), quality (valid / stale / unavailable / invalid), evidenceStatus (confirmed / likely / unknown). confirmed означает наличие конкретного пути/декодера в проверенном upstream; не гарантирует работу на G07. В демо все runtimeSource=mock; в режиме чтения measured присваивается только данным из разрешённых callback; качество и источник не смешиваются, поэтому возможен stale mock.

Для независимости от UI выделить типизированный read-only TelemetryProvider с подпиской/снимком и очисткой. В этом релизе только MockTelemetryProvider. Не создавать диагностические сокеты, CAN, UDS/SOME-IP транспорт, записи/очистку DTC, управление подвеской/DSC/HDC, security access или скрытые vehicle-control stubs.

Первый MGU adapter реализован в native/src/vehicle с allowlist подтверждённых в upstream чтений (не проверенных на G07). Неподтверждённые адреса остаются пустыми. Состояния 0, false, unknown и stale различаются.

## Локальный симулятор и сессия

- Сценарии: «Горная тропа», «Подъём», «Диагональное вывешивание», «Спуск с HDC», «Нет части данных». Они меняют только mock data.
- Пауза/продолжение демо: значения и время сессии перестают меняться; возобновление не скачет на пропущенное реальное время.
- «Новая сессия» сбрасывает накопления и время; новый текущий валидный отсчёт служит первым измерением. Переключение сценария не должно незаметно сбрасывать сессию.
- Сессия в памяти: время, max |pitch| / |roll|, min/max altitude, max slip overall и по колёсам, пиковый момент двигателя, max температуры АКПП/масла/ОЖ, max размах высот. min/max altitude начинают с первого валидного отсчёта, не с 0.
- Не накапливать unavailable/stale/NaN; paused data не добавляет дистанцию/время. Набор высоты не считать суммой GPS-шума; для первой версии достаточно min/max и изменения от старта.
- Локальные контролы доступны мышью и клавиатурой; вкладки поддерживают очевидный focus/активное состояние. Уважать prefers-reduced-motion. Никаких внешних сетевых запросов телеметрии.

## Технологии и перенос

TypeScript + React + Vite, лёгкий CSS, собственные SVG-слои и подготовленный PNG с alpha. Не тянуть UI kit, сервер, базы данных, WebGL/Three.js без необходимости. Слои: domain/types, providers/mock, domain/session (чистые функции), i18n/ru (+ en skeleton), components, screens. Runtime data и session calculations не зависят от React. Для просмотра без dev server дополнительно собирается автономный preview.html из того же Vite build.

idrive7-apps использует собственный JS runtime/scene graph и native render engine, а не DOM-браузер. React/CSS не являются готовым MGU пакетом. В native/ переиспользуются типы, математические правила, словарь и сценарии; renderer/input/lifecycle адаптированы к native canvas и HMI. Детали — NATIVE_PORT.md. Этот релиз не содержит install-to-car scripts и не объявляется MGU-совместимым.

## Приёмка первой итерации

1. npm install, npm run build и подходящие проверки TypeScript проходят.
2. Все пять вкладок работают; все обязательные сигналы видны хотя бы на одном экране.
3. Основные подписи на русском; единицы/формат чисел единообразны; FL/FR/RL/RR расшифрованы.
4. Во всех состояниях постоянно видна маркировка демо. Сценарии, пауза и новая сессия работают.
5. В демо проверены отдельно stale и unavailable; валидные 0/false сохраняются. Потерянные данные не превращаются в 0; знак углов не теряется; max/min рассчитаны корректно и не обновляются по stale/invalid.
6. Проверены desktop, MGU-wide и компактный/mobile layout без горизонтального обрезания главных элементов.
7. Значимые проверки для session aggregates, invalid samples и pause/reset; не писать тесты, дублирующие CSS.
8. Сделаны скриншоты пяти экранов и компактного вида, записаны фактические результаты проверки.
9. README объясняет запуск, mock-only scope, ключевые ограничения переноса. ITERATION_02.md описывает следующие задачи и необходимые проверки на G07.
