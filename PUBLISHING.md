# Публикация xDrive Offroad Pro

Публичный репозиторий: https://github.com/usbkrapal/xdrive-offroad-pro

Версия 0.1.3 собрана одним выпуском: приложение, служба камер и видеоприёмник. По умолчанию включены данные автомобиля. Реализованы передняя и обе боковые камеры, но их работа и новые диагностические показания на G07 ещё не подтверждены. Отсутствующие показания не заменяются демонстрационными.

## Установка через интернет

После появления готового выпуска `catalog` в Releases:

1. На стоящем автомобиле обеспечить стабильное питание и интернет; MGU Store должен показывать Online.
2. MGU Store → Settings → Add source: `usbkrapal/xdrive-offroad-pro`.
3. Выбрать Releases, затем Check now.
4. Открыть Terrain Monitor (подзаголовок xDrive Offroad Pro) и установить пакет, проверив название и версию.
5. При первом добавлении компонентов камер перезапустить головное устройство, чтобы зарегистрированная служба запустилась.
6. Обычный запуск — данные автомобиля. Сверить показания и три ракурса по [проверкам выпуска](QA_CAR_FIX_0.1.3.md).

Для публичного источника не требуется GitHub-токен. Не добавляйте адрес локального браузерного предпросмотра: localhost работает только на компьютере, где он запущен.

## Совместимость

Целевой профиль: iDrive 7, MGU Store 0.9.40, mgu-deploy 0.8.19, mgu-updater 0.8.45, mgu-render 0.6.21. Также сообщены mgu-python 1.0.3, mgu-uplink 0.7.12 и app-privacy 1.7.2. Версии подтверждены владельцем. Версия 0.1.2 проверена владельцем на G07; 0.1.3 проверена на компьютере по замечаниям этой проверки. Живые камеры и недостающие показания требуют подтверждения на автомобиле.

Пакет для Store не содержит BMW SDK. Установщик связывает его с SDK штатного приложения на самом MGU. Это поддерживается документацией mgu-deploy 0.8.19; извлекать SDK на компьютер для этого пути не требуется.

## Сборка объединённого выпуска

1. Собрать целевой `xop-camrx` по `native/packaging/xop-camrx/SOURCE-README.md`.
2. Выполнить `npm run native:package -- --repository usbkrapal/xdrive-offroad-pro --tag v0.1.3`.
3. Проверить `native/release/`: три установочных архива, соответствующий исходник GPL-приёмника, `catalog.json`, `mgu-store.json`, значок и `SHA256SUMS`. Проверяющий скрипт проверяет контрольные суммы, зависимости, состав архивов, Node 8 и ELF.
4. Опубликовать неизменяемые архивы в выпуске `v0.1.3`, затем обновить каталог источника `catalog`.

Нельзя публиковать один архив приложения без службы и приёмника: каталог содержит обязательную цепочку зависимостей. Исходник GPL-приёмника публикуется вместе с бинарным пакетом. Сборочные заглушки и библиотеки BMW в установочные архивы не входят.
