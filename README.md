# Terrain Monitor

xDrive Offroad Pro

Монитор для BMW MGU / iDrive 7: рельеф, сцепление, подвеска, системы и камеры. Русский интерфейс. Отдельный веб-прототип на React/TypeScript и нативное приложение для MGU.

**Версия 0.1.3: исправления по результатам проверки 0.1.2 владельцем на G07.** В 0.1.3 убраны нижний ряд «Рельефа», руль и нативные кнопки «Далее/Назад»; исправлены очередь диагностических запросов и запуск камер. Живые камеры, абсолютные крен/тангаж и все дополнительные показания на G07 пока не подтверждены. Подробнее: [QA_CAR_FIX_0.1.3.md](QA_CAR_FIX_0.1.3.md).

## Установка через MGU Store

1. Обеспечьте интернет в MGU Store (Online), автомобиль должен стоять со стабильным питанием.
2. Settings → Add source: **`usbkrapal/xdrive-offroad-pro`**.
3. Выберите **Releases**, нажмите **Check now**.
4. Откройте **Terrain Monitor → Install / Update**.
5. С 0.1.2 приложение запускается с данными автомобиля. Вкладки «Настройки» нет; сохранённый выбор «Демо» при обновлении сбрасывается на автомобиль.

Релиз `catalog` содержит каталог обновлений; пакеты размещаются в выпусках с номером версии. Не устанавливайте автоматически сгенерированный GitHub архив Source code как приложение. Пакет не содержит BMW SDK: mgu-deploy использует штатный SDK головного устройства. Публикация не требует GitHub-токена на автомобиле.

Подготовлено для ID7 и профиля MGU Store 0.9.40, mgu-deploy 0.8.19, mgu-updater 0.8.45, mgu-render 0.6.21. Совместимость с конкретной прошивкой требует проверки. Подробнее — [PUBLISHING.md](PUBLISHING.md).

## Данные и ограничения

Адаптер только для чтения. Фото 0.1.1 на G07 подтверждают поступление: обороты, момент двигателя, температуры масла/ОЖ, ускорения, рыскание, педаль, угол руля, передача P (из DataPowerTrain2), давления/температуры шин (BAR/°C). Поступление не равно независимой калибровке. Скорость читается так же, но в материалах 0.1.1 отдельно не подтверждена. BasicDataSet (доля xDrive и масло АКПП) на этой машине пока «недоступен, 0 отсчётов». Тогда эти поля «нет данных», без подстановок.

Частота: обороты, скорость, момент, ускорения и рыскание читаются 5 раз в секунду; руль и педаль — по мере уведомлений автомобиля; температуры — раз в 5 с, шины — раз в 10 с.

С 0.1.3 угол и рисунок руля удалены по просьбе владельца. Сырые данные уклона дороги остаются в скрытых сведениях: масштаб и соответствие абсолютному крену/тангажу не установлены.

Диагностическое чтение UDS идёт через головное устройство последовательно. Фото 0.1.2 подтверждают температуру АКПП 39 °C, тормозные давления и режим Comfort. Для скоростей колёс и датчиков высоты в 0.1.3 исправлены перегруженная очередь и повторы неотвечающих запросов; частота зависит от фактической длительности ответов и не гарантируется на уровне 5 Гц. Данные принимаются только для опознанного варианта блока. Уровень подвески показывает три описанных состояния EHC: низкий, стандарт, высокий; шесть уровней сценария не подставляются. Высота датчика не считается отклонением от нормального уровня. Момент осей, блокировка, ассистенты и абсолютные углы требуют подтверждения ответами автомобиля.

Камеры используют собственный приёмник и мост, установленные вместе с приложением. В 0.1.3 исправлены ожидание готовности до регистрации клиента и выбор между ICAM2/XView3D. Порядок окон: левая, передняя по центру, правая. Проверки на компьютере подтверждают работу программной цепочки, но не живое видео на G07. При недоступном видео скрытый лист показывает, на каком этапе остановилась передача. Демоизображения в обычном запуске не используются. [Карта сигналов](SIGNALS.md).

Нет команд управления автомобилем, записи в CAN/UDS, диагностических сессий, сброса ошибок, изменения подвески, DSC или HDC: из диагностики используется только чтение выбранных идентификаторов. Показания прототипа не предназначены для определения безопасного уклона или риска опрокидывания.

## Разработка

Доступ разработчика (не для обычной поездки) — только переменной окружения процесса приложения при запуске: `XOP_DEV=diag` добавляет на «Системы» кнопку листа диагностики чтения (сервисы, счётчики чтений, последние сырые числа с временем получения, состояние рендерера и контроллера); `XOP_DEV=demo` (или `demo=<сценарий>`) — демо вместо автомобиля с постоянной меткой «ДЕМО»; вместе — `XOP_DEV=demo,diag`. Ничего из этого не сохраняется. В обычном запуске диагностические сведения (вердикты опознания блоков, первые ответы с сырыми байтами, ошибки и восстановление, первые отсчёты полей, сводка интервалов раз в 5 минут) пишутся только в журнал приложения, без повторов и без идентификаторов автомобиля; в обычном интерфейсе не выводятся. Для фото сведений без ноутбука: откройте «Камеры» или «Системы» и пять раз за три секунды коснитесь уже активной вкладки; открывается лист со снимком, кнопкой «Обновить» и прокруткой. Штатная «Назад» закрывает его. Этот жест не включает демо и не меняет настройки.

Нужны Node.js 22+ и Python 3. Для нативного runtime собирается совместимый с Node 8.7 CommonJS.

```sh
npm ci
npm test
npm run native:typecheck
npm run native:test
npm run native:build
npm run native:package -- --repository usbkrapal/xdrive-offroad-pro
```

Веб-прототип: `npm run dev`. Браузерная production-сборка: `npm run build`. Артефакты публикации: `native/release/`. На MGU не требуется устанавливать Node/npm/React: используется уже собранный нативный пакет.
