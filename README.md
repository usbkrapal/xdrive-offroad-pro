# Terrain Monitor

xDrive Offroad Pro

Экспериментальный монитор для BMW MGU / iDrive 7: рельеф, сцепление, подвеска, системы и камеры. Русский интерфейс, круглые приборы тангажа/крена и анимация работы привода непосредственно на узлах и шинах. Отдельный веб-прототип на React/TypeScript и нативная версия для MGU.

**Статус: версия 0.1.0 прошла первый запуск на G07; версия 0.1.1 исправляет обнаруженные проблемы и требует повторной проверки в машине.** По умолчанию работает DEMO. Иллюстрации камер — статические примеры, а не подключённые видеопотоки. Результаты первого запуска и исследование аналогов: [CAR_TEST_FINDINGS.md](CAR_TEST_FINDINGS.md).

## Установка через MGU Store

1. Обеспечьте интернет в MGU Store (Online), автомобиль должен стоять со стабильным питанием.
2. Settings → Add source: **`usbkrapal/xdrive-offroad-pro`**.
3. Выберите **Releases**, нажмите **Check now**.
4. Откройте **Terrain Monitor → Install / Update**.
5. Первый запуск — DEMO. Переключение на чтение автомобиля выполняется отдельно в настройках приложения.

Релиз `catalog` содержит каталог и пакет. Не устанавливайте автоматически сгенерированный GitHub архив Source code как приложение. Пакет не содержит BMW SDK: mgu-deploy использует штатный SDK головного устройства. Публикация не требует GitHub-токена на автомобиле.

Подготовлено для ID7 и профиля MGU Store 0.9.40, mgu-deploy 0.8.19, mgu-updater 0.8.45, mgu-render 0.6.21. Совместимость с конкретной прошивкой требует проверки. Подробнее — [PUBLISHING.md](PUBLISHING.md).

## Данные и ограничения

Адаптер только для чтения: базовые обороты, скорость, момент двигателя, температуры масла/ОЖ, ускорения и передача; дополнительно — угол руля, скорость рыскания, положение педали, давление/температура четырёх шин с учётом единиц автомобиля, передняя/задняя доля xDrive из BasicDataSet, температура масла АКПП из BasicDataSet. Последние два поля зависят от того, заполняет ли их прошивка. Декодеры основаны на изученных открытых MIT-исходниках; новые подписки ещё не проверены на G07. Фотографии первого запуска подтвердили поступление части базовых полей, но не их независимую калибровку.

Абсолютные тангаж/крен, высоты/уровень подвески, момент осей в Н·м, физическая пробуксовка, индивидуальные тормозные вмешательства, задняя блокировка, HDC/DSC/DTC и live-камеры пока не подключены. Работа камер в Drive Recorder из Store подтверждена владельцем, но поддерживаемый внешний live-интерфейс в исследованном клиентском коде не найден. В режиме автомобиля неизвестные, устаревшие и отсутствующие данные явно обозначены; автоматической подмены демо нет. [Полная карта сигналов](SIGNALS.md).

Нет команд управления автомобилем, записи в CAN/UDS, изменения подвески, DSC или HDC. «Сброс» очищает только статистику текущей сессии приложения. Показания прототипа не предназначены для определения безопасного уклона или риска опрокидывания.

## Разработка

Нужны Node.js 22+ и Python 3. Для нативного runtime собирается совместимый с Node 8.7 CommonJS.

```sh
npm ci
npm test
npm run native:typecheck
npm run native:test
npm run native:build
npm run native:package -- --repository usbkrapal/xdrive-offroad-pro --tag catalog
```

Веб-прототип: `npm run dev`. Браузерная production-сборка: `npm run build`. Артефакты публикации: `native/release/`. На MGU не требуется устанавливать Node/npm/React: используется уже собранный нативный пакет.
