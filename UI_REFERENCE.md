## Рекомендации для прототипа

1. Основное имя **Terrain Monitor**, подпись **BMW X7 · G07**, компактная метка **ДЕМО** всегда видна. Вкладки: **Рельеф**, **Тяга**, **Подвеска**, **Системы**; внутренние ключи `terrain/traction/suspension/systems`. Русский язык по умолчанию, все строки из словаря; в дальнейшем `en` без переписывания компонентов.
2. Страница «Рельеф»: крупная авторская SVG-схема внедорожника на ориентирующей плоскости; по сторонам углы продольного/поперечного наклона, ниже высота, угол руля, уровень подвески. Не обещать оценку риска опрокидывания: нет подтверждённой модели устойчивости.
3. Тяга: центральная схема трансмиссии и колёс; отдельные передняя/задняя доли, актуальный/модельный момент с явным происхождением; каждая из четырёх шин показывает wheel speed / slip / brake intervention. Связь колеса с числом должна быть очевидной.
4. Подвеска: четыре высоты с FL/FR/RL/RR и русской расшифровкой, дельты осей и сторон. Уровень подвески — статус, не управляющая кнопка. В демо выбирать **сценарий** вне основного приборного поля, чтобы выбор не выглядел командой автомобилю.
5. Системы: читаемые статусы HDC, DSC/DTC; передача, педаль, момент, температуры; схема давления и температуры шин. Не перегружать экран 20 одинаковыми карточками; группировать по задаче.
6. Сессионные максимумы компактной нижней полосой: |pitch|, |roll|, altitude, slip; добавить время сессии и максимальную разницу высот подвески. Кнопка «Сбросить сессию» только локальная.
7. Desktop: оболочка 1360–1600 px max-width, ощутимая горизонтальность. MGU-профиль **1920×720** с гарантированным отсутствием вертикального scroll в основном режиме, отдельный компактный профиль для preview 1600×600. Малые ширины складывают панели в колонку; не уменьшают все числа до нечитаемого размера.
8. Демо-сценарии «Каменистый подъём», «Спуск», «Диагональное вывешивание», «Нет данных» с паузой. Постоянная метка демо; missing/stale/unsupported отображаются явно. Управление только состоянием демо и навигацией, никаких автомобильных write/control APIs.
9. Обновление чисел 5 Hz достаточно для понятного прототипа; SVG-индикаторы можно интерполировать CSS. `prefers-reduced-motion` отключает плавные анимации. `font-variant-numeric: tabular-nums`, значения не должны дёргать ширину карточек.
10. Проверка: русский длинный текст, вкладки клавиатурой и указателем, fallback «Нет данных», семантические подписи колёс, 1920×720 и desktop viewport, перезапуск/сброс сессии. Скриншоты минимум по одному на каждый экран + компактный viewport.

## Граница переноса

React/Vite подходит для независимой проверки UI. DOM/CSS не является целевым MGU runtime. Делить проект на чистую модель сигналов/derived metrics, mock-provider, локализацию и visual components; при переносе переиспользуются модель/расчёты/словарь, а представление переписывается через проверенный MIT SDK-интерфейс. Это позволит сохранить визуальный язык и не вводить GPL renderer в web bundle.
